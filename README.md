# VulnForge

VulnForge is a cloud-native security engineering project built on AWS.

## Current Infrastructure

- AWS VPC
- Public and private subnets
- Internet Gateway
- S3 Gateway VPC Endpoint
- Security Groups
- Amazon EC2
- Docker

## Planned Infrastructure

- Application tier
- PostgreSQL database
- Application Load Balancer
- Terraform infrastructure
- Amazon EKS
- Kubernetes workloads
- CI/CD
- Container security
- Vulnerability scanning
- Observability

## Architecture

The project is being built incrementally to understand AWS networking,
compute, containers, security, infrastructure as code, and Kubernetes.
